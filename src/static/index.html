ทดสอบการให้คะแนน

กรอกลักษณะที่โมเดลทำนาย พร้อมความมั่นใจ แล้วดูว่ากฎกลุ่มไหนได้คะแนนสูงสุด 3 อันดับ — เหมือนที่ /api/classify ทำจริงทุกครั้งที่มีรูปเข้ามา

จัดอันดับยังไง?

เรียงด้วย Matched ก่อน — นับว่าตรงกี่ช่องจาก 4 ช่อง เสมอกันค่อยใช้ Score ตัดสิน (Score = ผลรวมความมั่นใจของช่องที่ตรง)

ที่ threshold 0.6 ตามค่าจริงในระบบ สองวิธีนี้ให้ผลเหมือนกันเสมอ (ช่องที่ตรงบวกอย่างน้อย 0.6 อยู่แล้ว ตรงมากกว่าจึงคะแนนมากกว่าเสมอ) จะต่างกันก็ต่อเมื่อลด threshold ลงมาต่ำ ๆ ในหน้านี้ — เรียงด้วย Matched ก่อนเพื่อให้ผลตรงกับที่คาดเสมอ

  • ช่องที่ ตรงกับกฎ และมั่นใจพอ → Matched +1, Score + ค่าความมั่นใจ
  • ช่องที่ความมั่นใจ ต่ำกว่า threshold → Matched +0.5, Score +0.5 ไม่ว่าตรงหรือไม่ตรง (โมเดลไม่มั่นใจ ไม่ควรตัดกลุ่มนั้นทิ้ง)
  • ช่องที่ไม่ตรงและมั่นใจ → ได้ 0 ทั้งคู่
  • Matched และ Score เท่ากันหมด → เรียงตาม Code

เพิ่มกลุ่มใหม่

กฎหนึ่งข้อทำงานยังไง?

หนึ่งกลุ่ม = หนึ่งชุดลักษณะ เวลามีรูปเข้ามา โมเดลจะทายลักษณะ 4 อย่าง (Shape / Apex / Base / Margin) แล้วเทียบกับทุกกลุ่ม กลุ่มที่ตรงมากที่สุดคือคำตอบ

ถ้ายังไม่มีกลุ่มไหนตรงครบ 4 ช่อง ระบบไม่ทิ้งว่าง — จะเลือกกลุ่มที่ตรงมากที่สุดเท่าที่มี ดังนั้นยิ่งใส่กฎครบ ผลยิ่งแม่น

เลือกช่องละ 1 ค่า ครบทั้ง 4 ช่อง = 1 กฎ ห้ามมีกลุ่มไหนใช้ชุดค่าซ้ำกัน ความเป็นไปได้ทั้งหมดคือ 4 × 4 × 4 × 2 = 128 แบบ

เพิ่มชนิดมัน

ชนิดมันคืออะไร?

ชื่อพันธุ์มันที่อยู่ใต้กลุ่มการจำแนก เช่น มันเสือ อยู่ในกลุ่ม G1 หนึ่งชนิดอยู่ได้กลุ่มเดียว และชื่อห้ามซ้ำกับชนิดอื่นในระบบ

ชนิดมันไม่มีผลต่อการให้คะแนน — /api/classify คืนแค่ id กับชื่อกลุ่ม ปลายทางเอา id ไปดึงรายชื่อชนิดมันเอง กลุ่มที่ยังไม่มีชนิดมันก็จำแนกได้ตามปกติ

ใส่ได้หลายชื่อพร้อมกัน — กด “+ เพิ่มชื่อ” เพื่อเพิ่มบรรทัด ชื่อที่ผิดจะฟ้องใต้บรรทัดนั้น
